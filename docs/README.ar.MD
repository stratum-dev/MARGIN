التنفيذ الرسمي للورقة البحثية. يوفر هذا المستودع خطوط التدريب والتقييم الكاملة لإعادة إنتاج النتائج.

## الملخص

![](./assets/banner.png)

يُعد اكتشاف ثغرات البرمجيات أمرًا بالغ الأهمية لضمان أمن وموثوقية البرمجيات. على الرغم من التقدم الحديث في التعلم العميق، تعاني مجموعات بيانات الثغرات الواقعية من تحديين رئيسيين: عدم توازن التكرار وعدم توازن الصعوبة. نعيد تفسير هذين التحديين من منظور هندسة فضاء التضمين، حيث نلاحظ أن عدم التوازن هذا يؤدي إلى تشوهات هندسية في فضاء التمثيل فائق الكروي. لمعالجة هذه المشكلة، نقترح MARGIN، وهو إطار قائم على التعلم المتري يتعلم تمثيلات تمييزية للثغرات من خلال تعلم متري بهامش تكيفي ونمذجة النماذج الأولية فائقة الكروية. يضبط MARGIN التنظيم الهندسي ديناميكيًا وفقًا لبنية التوزيع المقدرة بواسطة تركيز فون ميزس-فيشر، مما يحاذي الكتلة الاحتمالية لتوزيعات التضمين مع خلايا فورونوي المقابلة لها، وبالتالي يقلل التشوه الهندسي وينتج حدود قرار أكثر استقرارًا. تُظهر التجارب الموسعة على مجموعات بيانات الثغرات العامة أن MARGIN يتفوق باستمرار على النماذج المرجعية القوية، محققًا تحسينات ملحوظة في التصنيف والكشف، خاصة على مجموعات البيانات غير المتوازنة والصعبة. يُظهر التحليل الإضافي أن MARGIN ينتج هندسات تضمين أكثر تنظيمًا، مما يحسن المتانة وقابلية التفسير والتعميم.

## المتطلبات

- **ذاكرة GPU**: ≥ 24 جيجابايت
- **CUDA**: وقت التشغيل 12.4 (قد يعمل تعريف الإصدار ≥ 525 أيضًا عبر التوافق العكسي)
- **CPU**: x86-64، ≥ 4 أنوية
- **RAM**: ≥ 8 جيجابايت
- **مساحة القرص**: ≥ 2 جيجابايت لمجموعة البيانات، ≥ 5 جيجابايت للنماذج الأساسية
- **نظام التشغيل**: Linux (تم اختباره على Ubuntu 22.04 / 24.04)

## التثبيت

### 1. إنشاء بيئة conda

```bash
conda env create -f environment.yml
conda activate margin
```

### 2. تثبيت PyTorch

(إصدارات CUDA 12.4 — مستضافة على pytorch.org، وليس PyPI)

```bash
pip install torch==2.6.0+cu124          \
            torchvision==0.21.0+cu124   \
            torchaudio==2.6.0+cu124     \
            --index-url https://download.pytorch.org/whl/cu124
```

### 3. تثبيت HuggingFace CLI

```bash
pip install -U "huggingface_hub"
```

## التنزيل

مجموعة البيانات والنماذج الأساسية مستضافة على HuggingFace. يمكنك تنزيلها يدويًا باستخدام أدوات CLI.

### مجموعة البيانات

```bash
hf download codemetic/MARGIN --repo-type=dataset
```

### النماذج الأساسية

```bash
hf download Salesforce/codet5-base
```

> **للمستخدمين في الصين القارية:** قم بتعيين نقطة نهاية مرآة HuggingFace قبل أي أمر `hf download`:
> ```bash
> export HF_ENDPOINT=https://hf-mirror.com
> ```

## التدريب

قم بتشغيل `python main.py --help` لعرض جميع المعلمات المتاحة. المعاملات الفائقة ذات الصلة مذكورة في الورقة.

مثال على أمر التدريب:

```bash
python  main.py                                           \
        --dataset_subset          bigvul                  \
        --backbone_name           Salesforce/codet5-base  \
        --max_epochs              200                     \
        --max_checkpoints         3                       \
        --early_stopping_patience 30                      \
        --base_scale              20                      \
        --device                  cuda:0                  \
        --seed                    42                      \
        --batch_size              16
```

**ملاحظة:** قد تختلف نتائج التدريب والتقييم قليلاً عن الورقة الأصلية بسبب الاختلافات في بنية المنصة والعتاد وإصدارات البرمجيات.

## التقييم

```bash
python eval.py
```
